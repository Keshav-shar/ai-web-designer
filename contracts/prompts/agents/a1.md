Give the downstream design agent thoughtful creative latitude: it should honor the visual references, palette, and user query while adapting section structure, element count, and component placement naturally rather than forcing rigid hard-coded constraints.

Include the following sections and details:

- **`design_system_name`, `aesthetic_direction`, and `query_context`**:

  - `aesthetic_direction`: Describe the era, materials, mood, and signature visual moves grounded in what the reference images actually show.
  - `query_context`: Briefly explain what the site is, how it should feel, and how it fits the user's intent, in the user's own terms (not the catalog's labels), steering clear of any `avoid` vibes.

- **`color_palette_distribution`**: Organize colors into four groups—`text_colours`, `muted_accents`, `background_element_colours`, and `overlay_element_colours`. For each color, provide an evocative `name` (e.g., `"Vintage Coral Red"`), its `hex`, where it is used on the page (`usage`), and its `source`. Prioritize allowed hexes and observed reference colors, adding supplementary colors where genuinely helpful for contrast, legibility, or visual balance.

- **`role_map`**: Map hex values from your palette to functional roles—including `bg_primary`, `bg_secondary`, `text_top_heading`, `text_subheading`, `text_body`, `text_inverse`, `accent_muted`, `overlay_primary`, `overlay_secondary`, and `cta_fill` (plus any helpful supporting roles). Ensure sufficient contrast and legibility between text and the surfaces they sit on.

- **`typography`**: Define five type levels—`wordmark`, `display`, `subheading`, `accent`, and `body`. For each level, specify `family` (preferring suitable Google Fonts from `font_pool`, and stepping outside when the reference typography calls for a better match), `weight`, `case`, `letter_spacing`, `italic`, `classification`, `visual_traits` (observed stems, hairlines, terminals, swashes, width), `reference_style`, `size_css` (e.g., `clamp(3.5rem, 6vw, 5.5rem)`), and `line_height`. For `display`, also describe `shadow_treatment` or surface styling. Follow with `text_treatment_rules` explaining how headlines versus UI and body text are styled so body and utility copy stay clean and readable.

- **`background_layer`**: Specify `alignment_mode` (`exact_adapt` when the background reference fits the subject well, `nuance_extract` when adapting mood/color/light from an off-subject or looser reference), `use_background_image`, and `treatment` (`photo_fill`, `tinted`, `masked_radial`, or `none`—treating off-subject imagery softly so color and atmosphere carry without competing with content). Note any `ignored_irrelevant_subjects`, describe `base_surface`, and list the backdrop `elements` (textures, gradients, rays, patterns, shapes).

- **Layer Elements (`elements`, `midground_decor`, `foreground_overlays`)**: For each element, provide an `id`, `what` (what it is, named colors and hexes, opacity, and surface/texture), `geometry` (general form, layering, proportions, edge treatment, and styling cues so the design agent can render it naturally without rigid pixel-locking), `where` (approximate placement, anchoring, scale, and breathing room around content), and `source`.

- **`centerpiece`**: Indicate whether the page uses a central visual (`use`), describe what it depicts (`description`), and state `where` it sits.

  - When false, if a centerpiece fits the concept, treat the reference images as style/material inspiration and write a concise drawing brief for the subject's form, pose/composition, line/edge character, shading/finish, and named hex colors.

- **`midground_decor` and `foreground_overlays`**: Describe supporting depth elements (`midground_decor`, behind content) and subtle accent details (`foreground_overlays`, near edges/corners and clear of body text)—such as ribbons, arches, badges, frames, or marks—adapting what fits the design rather than forcing unused tropes.

- **`content_sections`**: Walk through the page from top to bottom (`nav`, `hero`, and whichever sections serve the brand and query—such as `intro`, `features`, `cards`, `quote`, `cta`, `footer`). For each section, include `section_id`, `role`, `where` (layout width, spacing/padding, surface treatment), and `what` (the components inside, their color and typography pairings, and how they are arranged).

- **`composition_and_overlap_rules`**: Define `alignment_grid`, `permitted_overlaps` (which elements may overlap and why the contrast in z-index, shape, edge treatment, texture, or color keeps them legible and well aligned), and `prohibited_overlaps` (such as placing busy decor behind body copy or crowding primary actions, be well aware of every element dimensions to prevent unexpected overlaps).

- **`layout_spec`**: Summarize the structural rhythm and section flow (`nav`, `hero`, supporting sections, visual density, and responsive behavior) to guide a clean, adaptable page build.

- **`strategic_cards`**: Provide a concise set of feature or value cards tailored to the brand (typically 0–4 cards), each with a short `tag`, a concise `heading`, brief `body` copy, and an `accent_color_key` tied to the palette.
